# Todo App

A simple and responsive Todo List application built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Simple and easy-to-use interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use

1. Enter a task in the input field.
2. Click the **Add** button.
3. Click **Done** to mark a task as completed.
4. Click **Delete** to remove a task.

## Project Purpose

This project was created as a personal software development project to practice building interactive web applications using HTML, CSS, and JavaScript.
